# Глава 9 — Гауссовский финал

Полные анонимные условия хранятся в каталоге. В главе 11 обязательных задач S09-Q01–S09-Q11; исключений нет. Уроки следуют маршруту: теория с примерами → интерактивный эксперимент → два атомарных упражнения → полная задача с доказательством → задачи для решения на бумаге.

## Карта задач

| ID | Основной результат | Интерактив и финальная проверка |
|---|---|---|
| S09-Q01 | Для равномерной точки четверти круга `Cov(ξ,η)=1/(2π)−16/(9π²)` | Полярные секторы; отдельно `Eξ`, `Eη`, `Eξη`, затем ковариация |
| S09-Q02 | `η=εξ∼N(0,1)`, `Cov(ξ,η)=0`, но пара не является гауссовской | Две прямые `η=±ξ`; доказательство симметрии и контрпример линейной комбинацией |

| S09-Q04 | `P(ξ>η)>1/2` не задаёт порядок ожиданий | Конструктор редкого большого убытка; явный контрпример |
| S09-Q05 | Независимость не даёт `P(ξ>η)=1/2`; для iid непрерывных даёт | Две движущиеся поддержки; контрпример и достаточные условия |

| S09-Q08 | Башня ожиданий для непрерывного вектора | Визуальное интегрирование совместной плотности по строкам и столбцам; доказательство через Фубини |
| S09-Q09 | Нормальные маргиналы не гарантируют гауссовский вектор | Диагностика линейных комбинаций на контрпримере `(Z,εZ)` |
| S09-Q10 | Для данной гауссовской пары `E[ξ|η=y]=y/3` | Линия условной регрессии; вывод коэффициента из ковариационной матрицы |
| S09-Q11 | Независимое присоединение `ζ∼N(0,1)` даёт полноранговый трёхмерный гауссовский вектор | Блочная матрица; явная плотность, определитель и доказательство гауссовости |

## Сохранение исходных условий

- S09-Q03 включает все три пункта. Ссылка на пример из учебника не нужна для прохождения: свойство башни выводится внутри урока.
- S09-Q06 содержит явное примечание об опечатке источника. Напечатанные условия о нулевой вероятности крайних интервалов для любого `ε>0` несовместимы с полной массой на `[a,b]`. Требуемая оценка доказывается при более общем и стандартном условии `P(a≤ξ≤b)=1`; исходная формулировка остаётся доступна в раскрываемом блоке.
- S09-Q07 сохраняет все три требования: закон `η`, формулу ковариации и вопрос о полноранговом гауссовском векторе.
- S09-Q11 явно выводит и плотность, и ковариационную матрицу.
