# Предел удачи / PROB//QUEST 0.2

**Игра должна обучать, а не угадывать, насколько человек уже выучил тему.**

## Запуск

- `play.html` — одиночный анонимный HTML; открывается двойным щелчком без сервера и npm.
- Для разработки в Codex / VS Code: распакуй папку, открой её и выполни `npm run dev` (Python 3). Затем открой `http://localhost:5173`.
- Тесты: `npm test`. Сборка автономного HTML из исходников: `npm run standalone`.
- Релизная сборка для GitHub Pages: `npm run pages`; результат появится в `_site/`.

## Что реализовано

- Сквозная карта **90 самостоятельных задач** из 9 анонимных разделов. Исключены две задачи со звёздочками и две задачи, зависящие от отсутствующего контекста.
- Полные формулировки задач хранятся непосредственно в анонимном каталоге приложения.
- 89 полноценных уроков из 90 задач курса.
- Учебный путь: **теория → манипулируемый эксперимент → атомарные вопросы → исходный босс**.
- Дроби/степени в числовых ответах, две подсказки, объяснения, локальное сохранение прогресса, XP за реальные уникальные шаги, прогресс по 9 главам, общий счёт 0/90.
- Любая ещё не реализованная задача **отображается открыто** со статусом «В разработке» и оригинальным условием. Игра не делает вид, что такой урок готов.
- Автономный формат без платных сервисов, серверной части, API и внешних зависимостей.

## Ограничения текущего прототипа

- Готовность уроков определяется флагами каталога и тестами. Реестр 90/90 — это **учёт**, а не заявление, что все уроки уже созданы.
- Похожие задачи в разных семинарах не склеиваются автоматически. Они учитываются как отдельные задания.
- Формулировки в реестре могут содержать упрощённую текстовую математическую вёрстку; сохраняй их допущения и подпункты.
- Некоторые задания явно требуют лекционного примера или раздела учебника — исходная лекция здесь не приложена. Нельзя выдумывать её содержание: помечай зависимость в уроке.
- Нет сервера для синхронизации между устройствами; localStorage привязан к браузеру и URL. При очистке данных прогресс исчезнет. Экспорт/импорт прогресса — задача для следующего этапа.

## Публикация

Workflow `.github/workflows/pages.yml` проверяет проект, собирает анонимный
автономный сайт и публикует его через GitHub Pages. Подробности — в
`docs/DEPLOYMENT.md`.
